# Pekopeko

Pekopeko is a long-term personal AI environment designed to combine multiple capabilities behind a single user interface. It aims to provide a unified, persistent personal AI assistant that evolves with the user over time.

## Project Status

This project is currently in its foundation/discovery phase. The specifications are authoritative for intended behavior and architectural decisions, and implementation has intentionally not started yet.

## Documentation

All documentation for Pekopeko is maintained in the `specs/` directory. This includes:

- Product vision and scope
- Architectural principles
- Module structure and interfaces
- Development tasks and tracking
- Architecture decision records

## Getting Started

Before modifying the project, developers and AI agents should read the relevant specifications in the `specs/` directory to understand the intended behavior and architectural decisions.

## Contributing

Please review the documentation in the specs directory before making any changes to ensure alignment with the project's vision and architecture.
