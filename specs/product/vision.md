# Vision

Pekopeko is intended to become a long-term personal AI environment, combining multiple capabilities behind a single user interface.

## High-Level Vision

The vision for Pekopeko is to create a unified, persistent personal AI assistant that evolves with the user over time. This system should serve as a comprehensive personal knowledge base and learning environment, integrating various specialized AI capabilities while maintaining a cohesive user experience.

## Current Product Direction

At this early stage, Pekopeko is focused on establishing a solid foundation for a modular personal AI environment. The core direction emphasizes:

- Creating a unified user experience that integrates multiple specialized capabilities
- Building a modular architecture that supports future expansion
- Establishing shared infrastructure and principles that will support long-term growth
- Maintaining focus on user privacy and data ownership

## Potential Future Capabilities

The system is expected to eventually provide capabilities such as:

- Personal AI assistance
- Persistent personal knowledge and memory
- Multiple specialized AI agents
- Retrieval and reasoning over personal information
- Personal data ingestion and processing
- Japanese language learning
- English language learning
- Text-based learning
- Voice-based learning
- Potential future modules and tools

## Important Distinctions

### Confirmed Product Direction
- Modular architecture with clear separation of concerns
- Single unified user experience despite internal modularity
- Focus on personal knowledge management and learning
- Emphasis on persistence and long-term user data retention

### Potential Future Capabilities
- Various learning modules (Japanese, English, text, voice)
- Specialized AI agents for different domains
- Advanced retrieval and reasoning capabilities
- Data ingestion and processing pipelines

### Things That Still Need to be Defined
- Specific implementation details of the modular architecture
- Final technology choices for databases, vector stores, LLM providers
- Exact user interface design and interaction patterns
- Detailed learning module specifications
- Integration approaches between different capabilities

## Architectural Principle

The important architectural principle is that Pekopeko is ONE PRODUCT / ONE USER EXPERIENCE, but internally it should be modular. This means:
- A unified GUI experience
- Modular internal components with explicit interfaces
- Shared core capabilities
- Clear boundaries between functional areas
